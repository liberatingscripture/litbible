# Email campaigns (`emails/`)

> Part of this repo's Claude docs; the index is in the root `CLAUDE.md`.

This folder is an **archive** of hand-built HTML campaigns. It is not part of
the site build, and **it is not a template source.** Newsletters are written
in Brevo's editor, which supplies the unsubscribe link and the footer. Don't
build the next one by copying a file here: they predate that and have
neither.
